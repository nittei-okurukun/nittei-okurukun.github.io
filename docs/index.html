日程調整、
3クリックでおわり。

メールを書きながら control＋⌘ command＋N。カレンダーから選ぶだけで、 候補日時の文面ができあがって、そのまま貼り付く。
コピーして、切り替えて、打ち直して……の往復とはさようなら。

macOS 13以降 無料 オープンソース 通信なし・ぜんぶローカル
無料でダウンロード ソースコードを見る

● つかいかた

1

control＋⌘ command＋N を押す

キーボード左下の control キーと ⌘ キーを押さえながら N。メールでもSlackでもメモでも、文章を打っているその場所で呼び出せます。Nは日程（Nittei）のN。忘れません。

2

日付 → 開始 → 終了

クリック3回で1枠。カレンダーは今日からの4週間だけを表示。複数の日も、同じ日の複数の時間帯も、続けて選べます。

3

コピーする

コピーと同時に、元のアプリへ自動で貼り付け。カーソルは書きかけの文章の続きにいます。

● できあがる文面

以下の日程でご予定はいかがでしょうか。
8月31日（月）　9:00〜12:00,14:00〜15:00
9月1日（火）　12:00〜13:00
9月10日（木）　9:30〜18:30

あいさつ文、曜日、日ごとの改行、同じ日の「,」区切り。
送る前に手で直すところが残らないよう、整形はぜんぶアプリにおまかせ。

● ダウンロード

かんたんインストール（おすすめ）

ターミナルにコマンドを1行貼り付けるだけで、ダウンロードから起動まで自動で進みます。ターミナルを使ったことがなくても大丈夫です。

  1. ターミナルを開く
    キーボードで ⌘ + スペース を押して、「ターミナル」と入力してEnter。文字を打ち込む画面が開きます。
  2. このコマンドをコピーして、「%」の右側に貼り付けてEnter 
    curl -fsSL https://raw.githubusercontent.com/nittei-okurukun/nittei-okurukun.github.io/main/scripts/install.sh | zsh
    あなたの名前@MacBook ~ % curl -fsSL https://raw.githubusercontent.com/nittei-okurukun/nittei-okurukun.github.io/main/scripts/install.sh | zsh

    こんなふうに「%」の右側に文字が入ればOK。あとはEnterキーを押すだけです。

  3. そのまま少し待つ
    「インストール完了」と表示されて、アプリが自動で起動します。最初に開く設定画面の案内に沿って アクセシビリティを許可すれば、control＋⌘ command＋N が使えるようになります。

zipでダウンロードする場合

こちらから最新版のzip をダウンロードして開き、出てきた「日程送るくん.app」を「アプリケーション」フォルダに移してから起動してください。
初回に「開発元を確認できません」と出たときは、システム設定 → プライバシーとセキュリティ の下のほうにある 「このまま開く」を押すと起動できます。
