● つかいかた

1

入力欄で ⌃⌘N

メールでもSlackでもメモでも。文章を打っているその場所で呼び出せます。アプリの切り替えはいりません。

2

日付 → 開始 → 終了

クリック3回で1枠。カレンダーは開いた瞬間から今月。複数の日も、同じ日の複数の時間帯も、続けて選べます。

3

コピーする

コピーと同時に、元のアプリへ自動で貼り付け。カーソルは書きかけの文章の続きにいます。

● できあがる文面

以下の日程でご予定はいかがでしょうか。
8月31日（月）　9:00〜12:00,14:00〜15:00
9月1日（火）　12:00〜13:00
9月10日（木）　9:30〜18:30

あいさつ文、曜日、日ごとの改行、同じ日の「,」区切り。
送る前に手で直すところが残らないよう、整形はぜんぶアプリにおまかせ。

● いいところ

入力中だけ、反応する

ホットキーが効くのはテキスト入力欄にいるときだけ。それ以外の⌃⌘Nはアプリにそのまま渡すので、ほかのショートカットを邪魔しません。

選択が消えない

選んでいる途中でほかのアプリを見に行っても、パネルも選択もそのまま残ります。コピーすれば、最後にいた入力欄へ貼り付け。

キーボードにやさしい

Enterでコピー、Escで閉じる。ホットキーは好きな組み合わせに変更でき、ログイン時の自動起動にも対応しています。

ぜんぶローカル

処理はMacの中だけで完結、ネットワーク通信はゼロ。予定の内容がどこかへ送られることはありません。ライト/ダークモードにも自動でなじみます。

● ダウンロード

無料でダウンロード 
curl -fsSL https://raw.githubusercontent.com/takumitakatani/nittei-okurukun/main/scripts/install.sh | zsh

ターミナルの1行インストールなら、ダウンロードから起動までそのまま進みます。 zipから手動で入れた場合は、初回のみ システム設定 → プライバシーとセキュリティ →「このまま開く」が必要なことがあります。 起動後、ホットキーのためにアクセシビリティの許可をお願いしています（用途は設定画面に書いてあります）。
