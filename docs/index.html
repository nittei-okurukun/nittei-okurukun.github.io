使い方 — HOW IT WORKS

01

入力欄で ⌃⌘N

メールでもSlackでもメモでも。テキストを打っている、その場所で呼び出せます。アプリを切り替える必要はありません。

02

日付 → 開始 → 終了

クリック3回で1枠。カレンダーは開いた瞬間から今月。複数の日、同じ日の複数の時間帯も、そのまま続けて選べます。

03

コピーする

クリップボードへのコピーと同時に、元のアプリへ自動で貼り付け。カーソルは書きかけの文章の続きにいます。

できあがる文面 — OUTPUT

以下の日程でご予定はいかがでしょうか。
8月31日（月）　9:00〜12:00,14:00〜15:00
9月1日（火）　12:00〜13:00
9月10日（木）　9:30〜18:30

あいさつ文、曜日、日ごとの改行、同じ日の「,」区切り。 送る前に手で直すところが残らないよう、整形はすべてアプリが引き受けます。

道具としてのこだわり — CRAFT

—

入力中だけ、反応する

ホットキーが発動するのはテキスト入力欄にフォーカスがある時だけ。それ以外の⌃⌘Nは元のアプリにそのまま渡すので、他のショートカットを一切邪魔しません。

—

迷う操作を削る

日付→開始→終了、以外の操作はありません。Enterでコピー、Escで閉じる。枠外をクリックしても閉じる。間違えた枠は×でひとつずつ消せます。

—

すべてローカル

処理はMacの中だけで完結し、ネットワーク通信はゼロ。予定の内容がどこかに送られることはありません。ソースコードも公開しています。

—

環境になじむ

ライト/ダークモードに自動追従。ホットキーは好みの組み合わせに変更でき、ログイン時の自動起動にも対応。メニューバーに静かにいるだけの常駐アプリです。

curl -fsSL https://raw.githubusercontent.com/takumitakatani/nittei-okurukun/main/scripts/install.sh | zsh
